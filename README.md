# 🛒 Carrito de Compras PHP

Proyecto desarrollado en PHP y MySQL usando XAMPP.

## 📌 Descripción

Este proyecto consiste en una tienda virtual con carrito de compras donde el usuario puede:

- Ver productos
- Agregar productos al carrito
- Visualizar el total de compra
- Vaciar carrito
- Navegar entre páginas

## 🚀 Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- XAMPP
- GitHub

## 📂 Estructura del proyecto

```bash
carrito_compras/
│
├── css/
├── conexion.php
├── index.php
├── carrito.php
├── agregar.php
├── eliminar.php
└── database.sql
```

## ⚙️ Instalación

1. Clonar el repositorio
2. Copiar la carpeta en:

```bash
xampp/htdocs/
```

3. Crear la base de datos:

```sql
carrito_db
```

4. Importar el archivo:

```bash
database.sql
```

5. Iniciar Apache y MySQL en XAMPP

6. Abrir en el navegador:

```bash
http://localhost/carrito_compras
```
